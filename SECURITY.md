# Security Policy

## Reporting Security Issues

Do not report security vulnerabilities through public GitHub issues, pull requests, or release comments.

Report suspected security issues through the agreed EN-CO OHG customer support or security contact channel. Include the affected Vision Realtime version, installation environment, reproduction steps, logs where appropriate, and any relevant network or runtime context.

## Supported Releases

Stable production releases receive priority for security review and remediation. Prerelease builds such as alpha, beta, and release-candidate versions are provided for validation and may be replaced without long-term support.

## Release Assets

Installers and corresponding source archives are distributed as GitHub Release assets from this repository. Verify that downloads originate from `https://github.com/ENCO-OHG/vision-realtime-releases/releases` before installing.
