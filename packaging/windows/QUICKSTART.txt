VISION REALTIME - WINDOWS QUICK START

Service name: VisionRealtime
Install folder: C:\Program Files\EN-CO OHG\Vision Realtime
Configuration: C:\ProgramData\EN-CO OHG\Vision Realtime\config\gateway.json
State: C:\ProgramData\EN-CO OHG\Vision Realtime\state\vision-realtime-state.json
Logs: C:\ProgramData\EN-CO OHG\Vision Realtime\logs

On first installation setup requests the Gateway Target ID, Controller ID, and
Controller Generation shown in Vision One. It then displays the generated
controller token once. Copy it into the Vision One IEC104 device settings.
Silent installs must provide /GATEWAY_TARGET_ID, /CONTROLLER_ID, and
/CONTROLLER_GENERATION; they never display secrets.

Edit gateway.json as an administrator, then restart the service:
  sc.exe stop VisionRealtime
  sc.exe start VisionRealtime

Normal uninstall preserves ProgramData. Select the purge option in the uninstaller, or run
the uninstaller with /S /PURGE, to delete all Vision Realtime ProgramData.

The service ZIP is intended for controlled manual deployment. Copy its
contents to a protected Program Files folder, create the ProgramData folders,
then generate a unique controller token and configuration from an elevated
PowerShell:
  powershell.exe -NoProfile -ExecutionPolicy Bypass -File initialize-config.ps1 -TemplatePath defaults\gateway.json -ConfigPath "C:\ProgramData\EN-CO OHG\Vision Realtime\config\gateway.json" -GatewayTargetId "<gateway-target-uuid>" -ControllerId "<vision-one-controller-uuid>" -ControllerGeneration 1

The manual command does not print the token. An administrator can read the
generated credentials.controller.token from the protected gateway.json and
enter it in Vision One.

Never copy defaults\gateway.json directly: its token placeholder is public and
the service rejects it at startup. Restrict the ProgramData tree to
Administrators, SYSTEM, and LocalService before starting the service. Then run:
  VisionRealtime.exe install
  VisionRealtime.exe start

To deregister a manually deployed service:
  VisionRealtime.exe stop
  VisionRealtime.exe uninstall
